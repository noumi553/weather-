# ⛅ Weather App

A simple and responsive Weather App that provides real-time weather information for any city around the world. This project uses live data from a weather API and displays temperature, humidity, weather condition, and more in a clean and user-friendly interface.

## 📌 Features

- 🌍 Search weather by city name
- ☁️ Real-time weather data (temperature, humidity, wind, etc.)
- 📍 Current location support (optional via Geolocation API)
- 🌡️ Shows weather conditions with relevant icons
- 📱 Fully responsive UI for mobile and desktop
